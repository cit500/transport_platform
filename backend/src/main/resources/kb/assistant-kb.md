# 韧安助手知识库

## 平台定位

交通网络多灾韧性评价可视化平台：以本地路网为数据底座，展示重车通行、灾害影响和灾后路网韧性分析。
行政区与路网数据只读，桥隧设施可维护；三类分析的汇总与设施/区域级结果均持久化到通用任务结果表，首页只发布已落库的结果。

## 功能模块

- **首页大屏**：地图（行政区划 / 卫星 / 电子三种模式）+ 数据概览 + 灾害动态滚动条。行政区模式可按韧性指数、路网连通度、灾害恢复能力任选一项着色，数值由低到高颜色从红黄渐变到绿。
- **重车通行评估**：按桥隧限载限界判定 可通行 / 条件通行 / 禁止通行，按每处桥隧最近一次成功评估展示结论。
- **灾害风险评估**：桥隧受损概率与 DS0–DS4 五级分级（DS0 为 0–20%，每级递增 20%）。
- **路网韧性评估**：区县韧性指数、路网连通度、灾害恢复能力三项指标。
- **数据管理**：桥隧设施维护（含桥梁/隧道专业详情、道路绑定）与分析任务的查询、明细查看、删除。

## 常见问答（预设口径）

- **平台有哪些功能？** 统一管理路网、桥隧，以及重车通行、灾害影响和区域韧性分析结果。
- **地图颜色代表什么？** 可切换韧性指数、路网连通度、灾害恢复能力，颜色由红到黄再到绿表示数值由低到高。
- **如何进行重车评估？** 左侧按每处桥隧最近一次成功评估展示通行结论；新任务只更新本次涉及的设施。

## 技术底座（被问及时可介绍）

前端 Vue 3 + Vue Router + Pinia + Leaflet + ECharts；后端 Java 17 + Spring Boot 3.2（Spring JDBC）；
数据库 MySQL 8（库名 transport_platform，含空间扩展）；地图瓦片来自 Bigemap 本地服务。
数字人助手本身由智谱 GLM 大模型（glm-4-flash，支持联网搜索）驱动：前端聊天面板 → 后端拼装上下文（本知识库 + 实时数据摘要）→ 通过 function calling 调用数据库只读工具核实数据 → 大模型生成回答；后端代码预留 Kimi 等兼容模型接口，切换只需改配置。
