## 2. 计算链与参数对齐（决策 2/4 的落点）

### 2.1 LLM 环境参数提示词重写（DebrisFlowService.SYSTEM_PROMPT）

**保留/改造**（对齐 predict 管线与 I-D 阈值输入）：

| 管线/I-D 输入 | 单位 | LLM 来源 | 说明 |
|---|---|---|---|
| rain_1h_mm | mm | LLM 新增 | 最近 1 小时雨量 |
| rain_6h_mm | mm | 现有 last6hMm | 改名对齐 |
| A | km² | 现有 catchmentAreaKm2 | 流域面积 |
| H | km | 现有 reliefM/1000 | 流域相对高差 |
| L | km | 现有 channelLengthKm | 沟道长度 |
| slope | 无量纲 | 现有 averageSlopeDegree→tan | 坡度 |
| **B / channel_width_m** | m | LLM 新增 | 平均沟道宽度（predict 与 I-D 都需要） |
| **D** | h | LLM 新增 | 场次降雨历时（I-D 判据；宽缓型 4<D<40，窄陡型 6<D<35） |
| **P_real** | mm | LLM 新增 | 场次累计降雨量（I-D 判据） |
| **P_prev1 / P_prev2** | mm | 替换现有 antecedentMm | 前一天/前两天雨量（I-D 有效雨量 0.85P1+0.85²P2） |

**新增输入框（默认专业值，LLM 估算可覆盖）**：

| 参数 | 默认值（专业值） | 说明 |
|---|---|---|
| fang_model | non_dam_break | Fang2019 模型类别（非溃坝） |
| region | jiangjiagou（蒋家沟） | 密度分区，查 dynamics_v1/density_regions_v1.json |
| W / Vd | 输入框留空→管线自算 | 泥石流体积（10000m³），Fang 成功输出为准 |
| density_kg_m3 | 随 region 查表默认（蒋家沟 2058.5） | 容重 |

**删去**（推理公式专用枚举，交接包正规流程不需要）：
`intensityMmH`（短历时雨强）、`last24hMm`、`antecedentMm`（由 P_prev1/P_prev2 替代）、
`looseMaterialLevel`、`soilMoistureLevel`、`channelCondition`。

### 2.2 平台侧 v/h 计算的处置

- **正式链**：predict 模式——平台把上述参数组装成 `parameters` 调交接包 `/api/assess`，由 Fang2019 管线算 v/h（保留 `parameter_sources` 来源追溯）
- 平台自研推理公式（Qb/Qc/曼宁迭代，DebrisFlowService.intensity）退役；强度指标 I 指数体系退役
- DS 概率、条件概率全部来自交接包返回；平台只做组装、落库与展示

### 2.3 I-D 阈值（决策 4）

- 输入：地形 A/L/H/B → J/F/M 因子 → 沟谷分类（M≤0.51 宽缓型，否则窄陡型）
- 判据：`I_cr = k·D^exp`（宽缓 20·D^-0.88，窄陡 7.7·D^-0.38），`R = I_real/I_cr`，R≥1 即达到阈值
- 输出 `threshold_reached` 是判定不是概率——前端展示"达到/未达阈值（R=0.83）"，**不得渲染成百分比概率**
- 附加：前期有效雨量 + 临界雨量参考（1h/1d 窗口，经验公式，非正时按包约定不外推）
- 请求方式：`/api/assess` 的 `rainfall_threshold_input`（结构参照 `frozen/data/xinqiao_sample.json`，带 value/unit/source）

## 4. 风险与注意

1. **Linux 运行**：包按 Windows 写的，`app.py` 用 `py -3.12` 启动方式需在 ECS 上以 `python3.12 -B -X utf8` 验证；NumPy 2.5.3 需 pip 源可用
2. **LLM 估算与专业默认值冲突**：输入框允许 LLM 覆盖但须展示"估算值"角标，与 parameter_sources 一致
3. **明洞流深固定**：用户给的流深与模型固定流深不符时走 `tunnel_fixed_depth_reference: true` 显式参考，前端要有提示
4. **桥墩演示墩仅 3.6/5.0m 两档**：下拉选择演示墩时流深输入锁定两档
5. **occurrence logistic**：本轮决策未采用（I-D 替换），包内该模型不上线
6. 密钥/端口：Python 服务只绑 127.0.0.1，不对外暴露，无鉴权需求
