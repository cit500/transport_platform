## 受众与目标

面向导师的阶段进展汇报。导师关注**项目整体状态、推进节奏、三位同学各自负责的部分、以及还差什么**，不关注算法公式与代码细节。因此全篇讲"做到哪一步、谁做的、下一步做什么"，技术术语只出现在必要处且不展开推导。

## 一、全局视觉约定

### ① 画布与安全区

- 画布 1280×720
- padding：上 60 / 下 60 / 左 60 / 右 60
- 内容区 1160×600
- 内容页统一：顶部深蓝标题条（高 68px，x=60..1220）+ 标题下 1px 贯通细线 + 底部页脚（y=670，左：项目名，右：页码）

### ② 配色（学术宝蓝 + 白底兜底）

| 槽位 | Hex | 用途 |
| --- | --- | --- |
| 主色 | `#1E4FA8` | 顶条、章节编号、强调字、关键框线 |
| 辅色 | `#3D7BD9` / `#E8EFF8` | 卡片描边、浅蓝底条、图表第二色 |
| 强调色 | `#D9534F` | 风险/未打通状态（≤3 处/页） |
| 正文色 | `#1A2230` / `#4A5568` / `#8B97A8` | 主/副/辅助文字 |
| 底色 | `#FFFFFF` | 主背景 |
| 辅底 | `#F7F9FC` | 局部卡片底、表头底 |
| 分隔线 | `#D6DCE5` / `#E5E7EB` | 1px 细线 |

纪律：白底 ≥60%；蓝族合计 20–40%；红黄合计 ≤5%；禁用紫/粉/金/渐变。

### ③ 字体与字号阶梯

- 中文：思源黑体（`Source Han Sans SC`/`Noto Sans SC`），西文与数字 Arial
- 封面主标 60px Bold / 副标 26px / 信息层 16px
- 章节扉页大数字 160px Bold（`#E8EFF8`）
- 顶条页主标 34px Bold（白字）
- 卡内小标题 24px Bold
- 正文 20px / 行高 1.5
- 表格 17px（表头 Bold）
- KPI 巨数字 72px Bold
- 页脚 14px

### ④ 视觉母题

每页内容页：顶部深蓝条 + 标题下 1px 贯通细线（`#D6DCE5`）+ 底部一句话浅蓝结论条（`#E8EFF8`）。结构图统一用白底 + 1px 灰描边方块，不使用阴影与圆角大于 8px 的卡片。

### ⑤ 配图

不使用生成图片。架构图、时间轴、衔接关系图均由 Box + Text 手绘（白底描边方块），保证信息真实、无装饰贴图。

## 三、逐页字段

### P1 封面
- type: cover / role: hero / rhythm: peak
- layout: 左对齐大字主标 + 副标 + 底部信息层，右侧留白
- anti_pattern: 禁止出现数据指标与数据说明；禁止装饰插画
- density: 字数约 60 / 图片 0 / 留白约 45%

### P2 目录
- type: catalog / role: supporting / rhythm: valley
- layout: 左列大标题「目录 CONTENTS」+ 右列 4 条编号章节 + 页码
- anti_pattern: 禁止统计装饰块（章节数/页数）、阅读顺序条、主线预告
- density: 字数约 80 / 图片 0 / 留白约 35%

### P3 / P6 / P10 / P15 章节扉页
- type: section / role: transition / rhythm: transition
- layout: 左侧 160px 浅蓝大数字 + 右侧章节名（40px Bold）+ 一句关键词
- 版式全篇统一；不加页脚
- anti_pattern: 禁止大段导语、看点列表

### P4 项目定位与研究目标
- type: content / role: supporting / rhythm: valley
- layout: 上半「背景与痛点」三行要点（浅蓝底条包裹）+ 下半 2×2 四格「研究目标」
- visual: 无图，纯结构
- anti_pattern: 禁止形容词堆砌标题；禁止每格只写一个名词
- density: 字数约 260 / 图片 0 / 留白约 20%

### P5 平台总体架构
- type: content / role: hero / rhythm: peak
- layout: 上部横向三层技术栈条（前端 / 后端 / 数据层），下部「1+3+1」业务结构图（首页+三模块+数据中心）
- visual: 手绘方块结构图，占内容区 ≥45%
- visual_role: anchor
- anti_pattern: 禁止等大卡片网格；禁止只画框不标职责
- density: 字数约 200 / 图 1（手绘） / 留白约 15%

### P7 团队分工

- anti_pattern: 禁止卡片内容长短悬殊；禁止加底色填充
- density: 字数约 240 / 图片 0 / 留白约 18%

### P8 进展时间轴
