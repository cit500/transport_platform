## 二、项目概况与目标（对应 PPT 第 3-5 页）

**背景与痛点**
- 西部山区路网桥隧密集、地质脆弱、灾害频发，叠加常态化重载运输，运行风险持续上升；
- 现有信息化系统多为单一业务监测，缺少桥隧管控、灾害评估、路网韧性的一体化联动；
- 重载审批与灾害应急仍靠人工整合数据、经验化研判，缺标准化可追溯的数字化支撑。

**四项研究目标**（据合同研究目的）
1. 搭建一体化信息化管理载体；
2. 实现分析成果的 GIS 可视化空间表达；
3. 固化分析流程，标准化提升决策响应能力；
4. 构建模块化、可扩展的工程化应用平台。

**平台架构**：前端 Vue 3 + JavaScript；后端 Java 业务服务（合同要求 Java + Python 协同，Python 侧待补）；MySQL 九张核心表；Bigemap 离线地图服务。业务上为「一个综合首页 + 三个专项模块（重载通行评估 / 灾害风险评估 / 路网韧性评估）+ 一个数据管理中心」。

## 四、平台开发进展（李应聪）

**本阶段完成的四项工作**（据 10-20 交流会）

1. **数据库改造**：将此前冗余的 40 余张表规范为明确的 9 张核心表；建立桥隧—路网关系表，新建桥隧时可快速定位应绑定的路网边（一个桥隧可对应多条路网边，一条路网边最多对应一个桥隧），用 DBeaver 直观管理；
2. **数字人助手**：接入联网大语言模型。流程为「用户提问（携带最近 10 条对话历史）→ 系统提示词（平台业务说明 + 数据库知识）→ 模型生成贴合平台语境的中文回答」，支持联网搜索实时信息；
3. **云服务器部署**：租用阿里云服务器（Ubuntu 24.04 LTS），完成环境搭建与前端、后端部署，**外网可直接访问 http://47.108.214.99/**；
4. **界面与工程规范**：借助开源框架统一平台视觉风格；使用 Git + GitHub 管理项目。

**平台已建成的能力**

## 五、桥隧灾害评估进展（莫东霖）

> 据《1103 灾害模块阶段汇报》

**已取得**

| 方向 | 进展 |
| --- | --- |
| 桥梁地震易损性 | 完成简化单柱桥墩地震响应及易损性计算 |
| 隧道地震易损性 | 完成典型隧道地震响应计算，形成阶段性易损性评估结果 |
| 泥石流发生倾向预测 | 基于降雨量等因子开展预测；**得分尚未校准为实际发生概率**（示例：前 6 小时降雨 30 mm → 未来 6 小时发生倾向得分 0.474） |
| 泥石流桥梁易损性 | 建立冲击荷载与桥墩损伤分析流程，初步实现流速—流深条件下的易损性快速评估 |
| 泥石流隧道（明洞） | 建立二维明洞基础模型、混凝土非线性损伤模型并完成静力验证 |

**主要瓶颈**（如实汇报）
- 泥石流桥梁：损伤判据待完善、部分阈值缺标定依据；目前主要考虑弯曲破坏，剪切等破坏模式尚未纳入；模型及随机参数缺乏实际工程数据支撑；
- 泥石流隧道：混凝土、钢筋及地基参数待完善；尚未开展 Abaqus 泥石流动力冲击分析；DS0—DS4 工程损伤判据尚未建立。

**下一阶段**
- 桥梁：完善桥墩损伤判据（补充剪切及弯剪破坏模式）→ 深化易损性分析（多种破坏模式与参数不确定性）→ 拓展不同桥型、桥墩参数及区域沟谷场景并做工程适用性验证；
- 隧道：完善钢筋与基础模型（等效配筋、基础边界条件）→ 开展泥石流动力冲击分析（不同流速下的结构响应）→ 建立损伤判据与易损性分析方法。

## 六、路网韧性评价进展（周星羽）

> 据《进展与计划》

**已做工作**：完成路网韧性初步模拟，链路为「路网建模 → 损伤模拟 → 维修恢复 → 韧性评价」，**已获得路网灾后功能恢复曲线**。路网基础数据处理与主要计算流程已完成，含 OD 代表点选取与交通流量分配、灾前能力评分、灾后蒙特卡洛抽样与功能曲线积分、关键道路初步筛选。

**下一步一：拓展路网功能指标**——从结构、冗余、运营三个维度评价路网功能，分层赋权后形成综合功能曲线 F(t)；统一灾前基准，固定 OD 需求与评价权重。

| 维度 | 指标 |
| --- | --- |
| 结构功能 N | 连通性、网络效率、结构熵、介数 |
| 冗余功能 D | 独立通道、替代路径、聚类系数 |
| 运营功能 T | 通行能力、需求服务、通行效率、拥堵影响 |

**下一步二：识别关键桥隧**——采用双图建模：Space-L 用于交通与功能计算，Space-R 用于桥隧位置分析；以介数、多跳桥接、混合度做结构位置分析，结合统一关闭后的功能损失形成关键桥隧排序。

**下一步三：桥隧风险分级**——给定灾害情景逐桥隧评价：损伤概率（读取已有易损性结果）→ 失效后果（枚举损伤等级、重算路网功能）→ 恢复期损失（计入恢复时间、累计功能损失）→ 风险分级（损失按概率加权，划分低/中/高风险），输出风险等级与空间分布。
